Will of Fire: The Last Ember: Privacy Policy

Last updated: 12 November 2026

The short version

Will of Fire: The Last Ember does not collect, store, send or sell any personal data. It has no accounts, no adverts, no analytics and no trackers.

Camera

The camera is optional. It is used only if you turn on "Weave with your camera" so the game can read your hand signs.

  • The video is processed on your own device, in real time.
  • No image, video or hand data is recorded, saved or sent anywhere.
  • The game is fully playable without the camera, using the on-screen sign pad.
  • You can turn the camera off in the game at any time, or remove the permission in your device settings.

Data the game keeps

None. The game does not save progress, settings or any identifier.

Internet

The app version contains everything it needs and does not contact any server while you play. The web version is a static page: your browser downloads the game files from GitHub Pages and the two typefaces from Google Fonts, and those hosts see the ordinary technical request (such as your IP address) that any website visit involves. The game itself receives none of it.

Children

The game does not knowingly collect information from anyone, including children.

Changes

If this policy changes, the new version will be published on this page with a new date.
